# The One-Line Laugh

Entry for the make.fun bounty
[The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f):
a program that writes one funny line to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

With no `MAKEFUN_OUTPUT_DIR` set it writes to `/output/entry.txt`
(the grader's mount). Standard library only, no network, no secrets.

## The line

> The only bill that gains weight when I ignore it is my gym.

One sentence, 59 characters — inside the gate's 1–200 characters.
The surprise lands in the last two words: a bill that gains weight
turns out to be the gym membership nobody uses.
